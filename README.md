# Running Coach

## 快速開始 (Quick Start)

1. **首先閱讀 AGENTS.md** - 包含 AIAgent 的基本規則
2. 在開始任何工作之前，遵循任務前合規檢查表
3. 在 `src/main/python/` 下使用正確的模組結構
4. 在每個已完成的功能之後提交

## 專案結構 (Project Structure)

標準專案結構，具有模組化組織：

```
src/main/python/
├── core/      # 核心業務邏輯
├── utils/     # 工具函數
├── models/    # 資料模型
├── services/  # 服務層
└── api/       # API 端點
```
